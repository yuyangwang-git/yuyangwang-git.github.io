植物命名法#

植物的名称大体上可划分为两类：

  • 普通名称 (common names)
  • 学名 (scientific names)

普通名称其实就是日常用语，如日常生活中常提到的：“玫瑰”、“百合”、“竹”等词汇。

学名就是根据国际上公认的命名规则给出的名称，如：“ Homo sapiens ”

那么“国际上公认的命名规则”是什么呢？针对植物的命名，现行规则有两个：

  • 国际藻类、真菌和植物命名法规 (International Code of Nomenclature for algae, fungi, and plants, ICN)
  • 国际栽培植物命名法规 (International Code of Nomenclature for Cultivated Plants, ICNCP)

ICN 旧称为国际植物命名法规 (International Code of Botanical Nomenclature, ICBN)

国际藻类、真菌和植物命名法规#

这一部分和中学生物所学相差不大，分类单元自上而下划分为界、门、纲、目、科、属、种这七个等级，如有需要，种下可继续划分为亚种、变种、亚变种、变型、亚变型，以向日葵为例：

中文名 学名
植物界 Plantae
被子植物门 Magnoliophyta
双子叶植物纲 Dicotyledoneae
菊目 Asterales
菊科 Asteraceae
向日葵属 Helianthus
向日葵（种） Helianthus annuus

简单来说，命名有两个基本特征：

  1. 采用拉丁文命名
  2. 种名采用双名法命名，即属名 + 种加词，种以上单元用单个词

例如，向日葵的种名为：Helianthus annuus，其中 Helianthus 为属名，annuus 为种名（种加词）。

国际栽培植物命名法规#

由于农业、林业和园艺中的栽培植物为了迎合人类需要，进行了极其混乱的杂交和选育，因此这些“物种”按照另一个规则——国际栽培植物命名法规——来进行命名。

ICNCP 中，“品种”是栽培植物的基本分类单位，分类单元只有三级：

  • 属
  • 种
  • 品种 (cultivar)

属名和种名既可以用拉丁文，又可以用非拉丁文化的俗名，但在属名上应尽可能和 ICN 保持一致。

品种名（cultivar）如果是在 1951 年之后才被确定的，就必须采用非拉丁文化的名称（甚至于汉语拼音也可以）。例如，金皇后白百合的命名为：

中文名 学名
百合属 Lilium
白百合（种） Lilium candidum
金皇后白百合（品种） Lilium candidum ‘Gold Queen’

很显然，“Gold Queen” 就是一个非拉丁文化的名称。事实上，这里的“品种”和我们日常生活中所说的植物品种一般情况下是一个概念。例如，我们在线上平台采购百合花时，会看到有一种百合被称为“索邦”，“索邦”正是该百合的品种名，其完整名称为 Lilium oriental 'Sorbonne'。

前面提到 ICN 中命名规则为：属名 + 种加词，从 Lilium candidum 'Gold Queen' 和 Lilium oriental 'Sorbonne' 可以看出，ICNCP 对栽培植物的命名规则为：属名 + 种加词 + 品种名。

ICN 和 ICNCP 到底有什么区别？#

最本质的区别其实就是适用对象不同：

  • ICN：适用于全世界的野生及自然起源的植物（包括藻类、菌类、低等与高等植物）
  • ICNCP：只适用于人类选育和生产的栽培植物

野生植物与栽培植物二者之间的本质差别在于：前者是自然选择的结果，后者则是人工选择的结果。

栽培植物的官方名称由谁在维护？#

栽培植物的官方名称由国际栽培品种登录权威（International Cultivar Registration Authority, ICRA）维护，而国际栽培品种登录权威是由国际园艺学会栽培品种登录特别委员会（ISHS Special Commission for Cultivar Registration）任命的。

每个 ICRA 负责一个或多个栽培植物群名称的审核与登录工作，从这里可以查阅到最新的 ICRA 列表。

举个例子，从上述 ICRA 列表中可以查阅得知，目前，中国花卉协会梅花蜡梅分会负责所有栽培梅花和腊梅的名称审核与登录工作，英国皇家园艺协会（The Royal Horticultural Society, RHS）负责百合花、杜鹃花、兰花等花卉的名称登录工作。

那么，知道 ICRA 有哪些成员，以及每个成员负责哪些花卉的名称维护，对我们有什么意义呢？主要有两点意义：

  1. 我培育出了一个新品种百合，想为其注册一个名称，这就需要联系负责百合名称登录的英国皇家园艺协会
  2. 我希望查阅所有百合花的品种名称和分类方法，这就可以前往 RHS 的官网，下载“国际百合名录和清单”，查阅我们需要的信息

本文将尽量采用 ICNCP 命名规则来记录养过的所有鲜切花卉。
